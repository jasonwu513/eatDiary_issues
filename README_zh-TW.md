## 關於 eatDiary
eatDiary 是一款基於 Flutter 開發的手機應用程式，旨在幫助用戶追蹤日常飲食、營養和飲食習慣。此倉庫專門用於收集錯誤回報、功能請求和用戶反饋。

## 如何回報問題

在建立新問題前，請：
1. **搜尋現有問題** 以避免重複
2. **查看常見問題解答**（如有）尋找常見解決方案
3. **更新至最新版本** 的應用程式

### 錯誤回報 🐛

回報錯誤時，請包含：

**必要資訊：**
- **裝置**：iOS/Android 版本和裝置型號
- **應用程式版本**：在應用程式設定中查看
- **重現步驟**：清楚的編號步驟
- **預期行為**：應該發生什麼
- **實際行為**：實際發生什麼
- **截圖/影片**：如適用

**錯誤回報範本：**
```
**裝置資訊：**
- 裝置：[例如：iPhone 14, Samsung Galaxy S23]
- 作業系統版本：[例如：iOS 17.1, Android 13]
- 應用程式版本：[例如：v1.2.3]

**錯誤描述：**
[清楚描述錯誤]

**重現步驟：**
1. 開啟應用程式
2. 導航至 [特定畫面]
3. 點擊 [特定按鈕/功能]
4. [繼續具體步驟]

**預期結果：**
[應該發生什麼]

**實際結果：**
[實際發生什麼]

**截圖/影片：**
[如適用請附上]

**其他備註：**
[任何其他相關資訊]
```

### 一般反饋 💬

對於一般建議、改進或問題：
- 使用「討論」或「問題」標籤
- 提供您使用應用程式的背景
- 具體說明您希望看到的改進

## 問題標籤

- 🐛 `bug` - 有東西無法正常運作
- ✨ `enhancement` - 新功能或請求
- 📱 `iOS` - iOS 特定問題
- 🤖 `android` - Android 特定問題
- 🔥 `critical` - 需要立即關注的重要錯誤
- 📋 `documentation` - 文件的改進或補充
- ❓ `question` - 需要更多資訊
- 💬 `discussion` - 一般討論主題

## 回應時間

- **重要錯誤**：我們目標在 24 小時內回應
- **一般錯誤**：我們目標在 3-5 個工作日內回應
- **功能請求**：我們目標在 1 週內回應
- **一般反饋**：我們目標在 1 週內回應

## 社群準則

1. **保持尊重** 和建設性的溝通
2. **提供詳細資訊** 以幫助我們理解和解決問題

4. **禁止垃圾訊息或宣傳內容**
5. **發布前先搜尋** 以避免重複問題
