## How to Report an Issue

Before creating a new issue, please:
1. **Search existing issues** to avoid duplicates
2. **Check the FAQ** (if available) for common solutions
3. **Update to the latest version** of the app

### Bug Reports 🐛

When reporting a bug, please include:

**Required Information:**
- **Device**: iOS/Android version and device model
- **App Version**: Check in app settings
- **Steps to Reproduce**: Clear, numbered steps
- **Expected Behavior**: What should happen
- **Actual Behavior**: What actually happens
- **Screenshots/Videos**: If applicable

**Bug Report Template:**
```
**Device Information:**
- Device: [e.g., iPhone 14, Samsung Galaxy S23]
- OS Version: [e.g., iOS 17.1, Android 13]
- App Version: [e.g., v1.2.3]

**Bug Description:**
[Clear description of the bug]

**Steps to Reproduce:**
1. Open the app
2. Navigate to [specific screen]
3. Tap on [specific button/feature]
4. [Continue with specific steps]

**Expected Result:**
[What should happen]

**Actual Result:**
[What actually happens]

**Screenshots/Videos:**
[Attach if applicable]

**Additional Notes:**
[Any other relevant information]
```

### Feature Requests ✨

For new feature suggestions:

**Required Information:**
- **Feature Description**: Clear explanation of the proposed feature
- **Use Case**: Why this feature would be useful
- **Priority**: How important this is to you (Low/Medium/High)

**Feature Request Template:**
```
**Feature Title:**
[Brief, descriptive title]

**Feature Description:**
[Detailed description of the feature]

**Use Case/Problem:**
[Explain the problem this feature would solve]

**Proposed Solution:**
[How you envision this feature working]

**Priority:**
[Low/Medium/High]

**Additional Context:**
[Any mockups, examples, or additional information]
```

### General Feedback 💬

For general suggestions, improvements, or questions:
- Use the "Discussion" or "Question" label
- Provide context about your usage of the app
- Be specific about what you'd like to see improved

### Issue Labels

- 🐛 `bug` - Something isn't working
- ✨ `enhancement` - New feature or request
- 📱 `iOS` - iOS specific issues
- 🤖 `android` - Android specific issues
- 🔥 `critical` - Critical bugs that need immediate attention
- 📋 `documentation` - Improvements or additions to documentation
- ❓ `question` - Further information is requested
- 💬 `discussion` - General discussion topics

### Response Time

- **Critical bugs**: We aim to respond within 24 hours
- **Regular bugs**: We aim to respond within 3-5 business days
- **Feature requests**: We aim to respond within 1 week
- **General feedback**: We aim to respond within 1 week

### Community Guidelines

1. **Be respectful** and constructive in your communications
2. **Provide detailed information** to help us understand and resolve issues
3. **Stay on topic** and keep discussions relevant to eatDiary
4. **No spam or promotional content**
5. **Search before posting** to avoid duplicate issues
